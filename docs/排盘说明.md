# 奇门遁甲 · 排盘说明

> 本文说明 `qimen-3d.html` 内置排盘引擎（`<script id="paipan">`）的**完整演算过程**。
> 每一步都给出「规则 → 依据 → 本盘实算值」，实算值由引擎直接输出，非手工填写。
>
> 示例盘：**2026-10-02 14:54（北京时间）** —— 与一张手机排盘软件的结果逐宫核对过。

---

## 〇、总览

```
输入：公历 年-月-日 时:分（北京时间 UTC+8）
  │
  ├─① 公历 → 儒略日 JD(UT)，ΔT 校正得力学时 JDE
  ├─② 太阳视黄经 λ → 定节气（24 节气把黄经切成 24 段，每段 15°）
  ├─③ 年柱：以「立春」为界
  ├─④ 月柱：以「节」为界（立春起的偶数序节气）
  ├─⑤ 日柱：儒略日锚点 + 六十甲子，子时换日
  ├─⑥ 时柱：五鼠遁
  │
  ├─⑦ 定旬：时柱在六十甲子中的位置 → 旬首、旬中序数、旬首之仪
  ├─⑧ 拆补法定元：回溯最近的甲/己日（符头）→ 上/中/下元
  ├─⑨ 局数：该节气的三元局数表 → 取对应元
  │
  └─⑩ 转盘：旬首之仪落宫 → 值符（本星）、值使（本门）
            → 天盘「值符加时干」→ 人盘「值使数旬」→ 神盘随值符
输出：阴/阳遁、局数、旬首、值符、值使、九宫四盘（神／天／人／地＋隐）
```

## 一、公历 → 儒略日

**规则**：把北京时间换成世界时，再用标准儒略日公式。

```
北京 2026-10-02 14:54  →  UT 2026-10-02 06:54
JD(UT) = 2461315.78750
ΔT(2026) = 75.1 秒      →  JDE = 2461315.78837
```

**为什么要 ΔT**：太阳位置是**力学时**的函数，而我们用的是世界时，两者差 ΔT。
2026 年 ΔT ≈ 70–75 秒，对节气时刻的影响只有约 1 分钟，属可忽略量级，但为求严谨仍做校正。

## 二、定节气（太阳视黄经）

**规则**：二十四个节气就是太阳视黄经的 24 个刻度，**每 15° 一个**，
以**立春 = 315°** 为起点。求出用事时刻的太阳视黄经 λ，它落在哪个 15° 区间，就是哪个节气。

| | |
| :-- | :-- |
| 太阳视黄经 | Meeus 低精度公式（几何平黄经 + 中心差 + 光行差 + 章动） |
| 本盘实算 | **λ = 189.1054°** |
| 区间判定 | 180°（秋分）≤ 189.11° < 195°（寒露）→ **秋分** |
| 秋分交节 | 2026-09-23 **08:08**（天文台实测 08:05，差 +3 分） |
| 下一节气 | 寒露 2026-10-08 14:29 |
| 阴/阳遁 | 节气序 i=15 → **阴遁**（冬至 i=21…芒种 i=8 用阳遁；夏至 i=9…大雪 i=20 用阴遁） |

> **注意**：`阳遁/阴遁` 只换地盘布仪方向，**不影响局数**。

## 三、年柱（立春为界）

**规则**：干支年以**立春**为界，不以元旦、也不以春节为界。

```
立春(2026) = 2026-02-04 03:55  ≤  用事时刻  →  干支年 = 2026
干 = (2026 − 4) mod 10 = 2  → 丙
支 = (2026 − 4) mod 12 = 6  → 午
年柱 = 丙午
```

> 公元 4 年为甲子年，故 `(年 − 4) mod 60` 即年干支序。
> **生于 1–2 月者必须用真实日期**——1 月到 2 月初属上一年（此处的「年命」输入同理）。

## 四、月柱（节为界）

**规则**：月柱以**十二节**（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）
为界，**不看中气**。立春起为寅月。

```
最近的「节」= 白露（i=14）@ 2026-09-07 22:41
月支序 = 2 + i/2 = 2 + 7 = 9  →  酉   （立春 = 寅 = 2）
月干   = 五虎遁(年干丙 → 正月庚寅) 的「庚」+ 7 = 3  →  丁
月柱 = 丁酉
```

**五虎遁**（年干定正月月干）：

| 年干 | 甲己 | 乙庚 | 丙辛 | 丁壬 | 戊癸 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 正月（寅月）月干 | 丙 | 戊 | 庚 | 壬 | 甲 |

## 五、日柱（儒略日锚点 + 子时换日）

**规则**：日干支由儒略日整数直接算出，锚点为 **JDN 2451545 = 2000-01-01 = 戊午日**
（戊午在六十甲子中第 54 位）。

```
JDN(2026-10-02) = 2461316
时 14:54 < 23  →  取当日（若 ≥23 则取次日，即「子时换日」）
干支序 = (2461316 − 2451545 + 54) mod 60 = 45
日柱 = 己酉
```

**子时换日**：23:00 起算次日。即 23:00–23:59 属「次日子时」，日柱用次日；
00:00–00:59 属「当日早子时」，日柱仍用当日。本引擎采用此主流口径。

---

## 六、时柱（五鼠遁）

**规则**：时支由钟点定（两小时一辰，子时跨 23:00–01:00）；时干由日干按五鼠遁推。

```
14:54 属 未时  →  时支序 = 7
时干 = (日干序 5 mod 5) × 2 + 7 = 7  →  辛
时柱 = 辛未，六十甲子中第 7 位
```

**五鼠遁**：`时干序 = (日干序 mod 5) × 2 + 时支序`（再 mod 10）。
对应口诀「甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途」。

## 七、定旬

**规则**：六十甲子每十个为一旬，旬首必是「甲×」。旬首之**仪**固定对应：

| 旬 | 甲子 | 甲戌 | 甲申 | 甲午 | 甲辰 | 甲寅 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| 旬首之仪 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |

```
时柱第 7 位 → 旬首第 0 位 = 甲子旬
XUN_STEPS（旬中序数，旬首 = 0）= 7
旬首之仪 = 戊
日柱所在旬 = 甲辰旬    ← 用于日空
```

> **这是最容易被写错的一步**：旬首宫是「旬首之仪在地盘所落之宫」，
> **并不恒等于局数宫**。只有当旬为甲子旬（其仪为戊）时，两者才重合。
> 本模型已修正这一点，并对非甲子旬加了断言。

## 八、如何定符头（与定元）

### 8.1 符头是什么

**符头 ＝ 甲日或己日。**

六十甲子中，天干为 **甲** 或 **己** 的日子每 **5 天**出现一次（甲子、乙丑、丙寅、丁卯、戊辰、己巳……），
所以符头天然就是「五日一元」的分界。**一元 = 五日 = 六十时辰。**

> ⚠️ **符头 ≠ 值符**。符头是**日层面**的一个日期，用来定「元」（上中下元）；
> 值符是**时层面**的一颗星，用来定盘面主导。两者没有任何从属关系——初学者最常混为一谈（详见 §10.4）。

### 8.2 六符头分三组（固定配属）

十二个符头按其**地支**固定分属三元，这是死表：

| 元 | 符头（甲/己日） | 地支类型 |
| :-- | :-- | :-- |
| **上元** | 甲子、己卯、甲午、己酉 | 子午卯酉（四仲） |
| **中元** | 甲寅、己巳、甲申、己亥 | 寅申巳亥（四孟） |
| **下元** | 甲辰、己丑、甲戌、己未 | 辰戌丑未（四季） |

所以「由符头地支定元」的实际操作，就是查上表：

| 符头地支 | 子 · 午 · 卯 · 酉 | 寅 · 申 · 巳 · 亥 | 辰 · 戌 · 丑 · 未 |
| :-- | :-- | :-- | :-- |
| 元 | **上元** | 中元 | 下元 |

### 8.3 定符头三步

```
① 取用事日的日柱（§5 已算出）
② 自当日往前回溯，找到最近的「甲日」或「己日」（含当日）
③ 该日即符头
```

**注意「含当日」**——若用事日本身就是甲日或己日，则它就是符头，无需回溯。

**回溯不超过 5 天**：因为甲/己日每 5 天必出现一次（`甲 乙 丙 丁 戊 己 庚 辛 壬 癸` 中甲在第 1 位、己在第 6 位，相隔 5）。

### 8.4 本盘实算

```
日柱 = 己酉（六十甲子第 45 位）
天干为「己」→ 己酉本身即符头，回溯 0 步
符头 = 己酉；其支 酉 ∈ 子午卯酉  →  上元
```

若用事日是「庚午日」（第 6 位），则需回溯：

```
庚午(6) → 己巳(5)  ← 天干为己，是符头
符头 = 己巳；其支 巳 ∈ 寅申巳亥  →  中元
```

### 8.5 为什么叫「拆补」

**交节日与符头日极少对齐**——一个符头的五日往往横跨两个节气。
拆补法的处理是：

> **节气照节气算（用太阳黄经定当前节气），元照符头算（用日柱回溯定元）。**

于是可能出现两种情形：

| 情形 | 处理 |
| :-- | :-- |
| 符头**在**交节日**之后** | 该节气从符头日起算，前一段「补」给上一节气 |
| 符头**在**交节日**之前** | 交节后先沿用该符头的元，把上元「拆」一部分给上一节气 |

两种情形都不需要额外判断——**因为规则是"元由符头定、节气由黄经定"，两者各算各的，天然兼容**。
这也是本引擎的实现方式，与主流排盘软件（拆补法）一致。

### 8.6 常见错误

| 错误 | 后果 |
| :-- | :-- |
| 用**节气日**而非**用事日**去回溯符头 | 元可能差一位，局数错 |
| 忘了「含当日」 | 恰逢甲/己日时会多回溯一轮，元错 |
| 把**符头**当**值符** | 两个层面混淆，整盘读错 |
| 用春节/元旦定年，而非**立春** | 1–2 月生人年柱差一年 |

## 十、转盘：值符与值使

**至此得到喂给模型的五个参数**：

```json
{"YANG": false, "JU": 7, "SHIGAN": "辛", "XUN_GAN": "戊", "XUN_STEPS": 7}
```

### 10.1 布地盘（三奇六仪）

**规则**：戊起于**局数宫**，阳遁**顺布**、阴遁**逆布**，次序为
`戊 己 庚 辛 壬 癸 丁 丙 乙`。

阴遁七局：戊兑七 → 己乾六 → 庚中五 → 辛巽四 → 壬震三 → 癸坤二 → 丁坎一 → 丙离九 → 乙艮八。

### 10.2 如何定值符

**值符 ＝ 旬首宫的「本星」。**

```
① 定旬首之仪（查 §7 的表）              本盘：甲子旬 → 戊
② 在地盘上找该仪所落之宫                本盘：戊在兑七宫   ← 这就是「旬首宫」
③ 取该宫的本星，即值符；该宫即值符本宫    本盘：兑七本星 → 天柱
```

**九星本宫表**（后天八卦固定配属，永不改变）：

| 宫 | 坎一 | 坤二 | 震三 | 巽四 | 中五 | 乾六 | 兑七 | 艮八 | 离九 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| 本星 | 天蓬 | 天芮 | 天冲 | 天辅 | 天禽 | 天心 | **天柱** | 天任 | 天英 |
| 五行 | 水 | 土 | 木 | 木 | 土 | 金 | 金 | 土 | 火 |

> 中五宫的天禽星寄于坤二宫天芮星，随天芮同行，故二者常合称「天芮禽」。

> ⚠️ **旬首宫 ≠ 局数宫**。旬首宫是「**旬首之仪**在地盘上的落宫」，局数宫只是「**戊**的落宫」。
> 只有甲子旬（其仪为戊）时两者重合——本盘恰为甲子旬，故都是兑七宫。
> 甲戌旬则不同：其仪为己，旬首宫是**己**落之宫，与戊宫无关。

**值符落宫（值符星飞到哪里）＝「值符加时干」**：

```
时干在地盘上落的那一宫，就是值符星要落的宫。
```

- 本盘：时干 **辛** 地盘在 **巽四宫** → 值符天柱落 **巽四宫**。
- **特例**：时干为「**甲**」时——甲不出现在地盘上（甲隐于六仪之下），
  此时以**旬首之仪**代之，即值符**不离本宫**，成「**伏吟**」（盘面不动）。
  本引擎已按此处理，并有断言覆盖。

**经典原文（两处可互相印证）：**

> 《烟波钓叟歌》：**「九宫逢甲为直符，八门值使自分明。符上之门为直使，十时一位堪凭据。
> 直符常遣加时干，直使逆顺遁宫去。」**

> 《太白阴经·遁甲》：**「直符者，六甲六仪是也。甲子常为六戊，甲戌常为六己，甲申常为六庚，
> 甲午常为六辛，甲辰常为六壬，甲寅常为六癸。」** 又：**「凡课式之法，常以直符加时干。」**

### 10.3 如何定值使

**值使 ＝ 同一个旬首宫的「本门」。**

```
① 取同一个旬首宫
② 取该宫的本门，即值使（值使门）
③ 值使落宫：自旬首宫起，按「宫数」阳遁顺行、阴遁逆行，数至时柱；旬首宫不计
```

**八门本宫表**（固定配属；中五宫无门）：

| 宫 | 坎一 | 坤二 | 震三 | 巽四 | 中五 | 乾六 | 兑七 | 艮八 | 离九 |
| :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- | :-- |
| 本门 | 休门 | 死门 | 伤门 | 杜门 | — | 开门 | **惊门** | 生门 | 景门 |

**「数至时柱」怎么数**：`XUN_STEPS = 时柱在旬中的序数`（旬首 = 0），所以**步数就是 XUN_STEPS**。

```
本盘：旬首宫 兑七 → 本门惊门  →  值使 = 惊门
      XUN_STEPS = 7   （甲子旬中辛未为第 8 位，旬首那一宫不计 → 7 步）
      按宫数逆行 7 步：兑七 → 乾六 → 中五 → 巽四 → 震三 → 坤二 → 坎一 → 离九
      ∴ 值使惊门落 离九宫
```

> **注意它穿过了中五宫。** 值使走的是**宫数序**（1→2→…→9，**含中宫**），
> 而天盘／神盘走的是**八宫环**（绕中宫转，**永不经过中宫**）。两套运动必须分开算。

**八门整盘环转**：值使落宫一旦确定，其余七门随值使**整盘刚性环转**——
把「本门在八宫环上从旬首宫移到值使落宫」所需的位移，施加到整张八门盘上。

```
八宫环序（顺时针）：巽四 → 离九 → 坤二 → 兑七 → 乾六 → 坎一 → 艮八 → 震三
环上位移 = (值使落宫的环序 − 旬首宫的环序) mod 8
本盘：兑七(环序 3) → 离九(环序 1)   位移 = (1 − 3 + 8) mod 8 = 6 步 = 270°
```

> 天盘却是 **5 步 = 225°**——**两个盘转的角度不一样**，这是正常的（两套算法、两个角速度）。

### 10.4 符头 / 值符 / 值使 三者对照（最常见的混淆）

| 名词 | 层面 | 是什么 | 怎么定 | 用在哪 |
| :-- | :-- | :-- | :-- | :-- |
| **符头** | **日** | 最近的甲日或己日 | 自**用事日**回溯（含当日） | 定**元**（上中下元）→ 定局数 |
| **值符** | **时** | 旬首宫的**本星** | 旬首之仪 → 地盘宫 → 本星 | 定盘面主导；加时干得**落宫** |
| **值使** | **时** | 同一旬首宫的**本门** | 旬首宫本门 → 按宫数数至时柱 | 定执行通道；带**八门整盘环转** |

> **一句话区分**：
> **符头在「日」上决定用哪一元，值符在「时」上决定谁是主帅，值使决定事情从哪道门走。**
> 三者分属两个层面，**互不隶属**。

### 10.5 天盘：值符加时干

**规则**：天盘是**整盘刚性旋转**（沿八宫环，每步 45°），
转到**值符星落在时干的地盘宫**为止。

```
时干 辛 地盘在 巽四宫
八宫环序（顺时针）：巽四 → 离九 → 坤二 → 兑七 → 乾六 → 坎一 → 艮八 → 震三
自兑七顺环数 5 步：兑七 → 乾六 → 坎一 → 艮八 → 震三 → 巽四
∴ 天盘环移 5 步 = 225°，值符天柱落巽四宫
```

**天盘奇仪随星同行**：每颗星携带其**本宫地盘之干**。故巽四宫显示「天柱 戊」。

### 10.6 人盘：值使数旬

**规则**：值使门**不按八宫环**走，而是自**旬首宫**起、按**宫数**（阳顺阴逆）数到**时柱**，
**旬首不计**；落宫确定后，其余七门随之**整盘环转**。

```
自兑七宫按宫数逆行数 7 步（旬首不计）：
兑七 → 乾六 → 中五 → 巽四 → 震三 → 坤二 → 坎一 → 离九
∴ 值使惊门落离九宫
环上等价位移：兑七 → 离九 = 6 步 = 270°
```

> **两条路线的关键差别**：
> **地盘/值使数旬走「宫数序」**（会穿过中五宫，在盘上是折线）；
> **天盘/神盘走「八宫环」**（绕中宫转，永不经过中宫）。
> 本盘天盘 5 步、人盘 6 步——**两个盘转的步数不同，这是正常的**，也是转盘奇门最容易记混的一点。

### 10.7 神盘

**规则**：八神**随值符**，自值符落宫起沿八宫环排布；阴遁逆布、阳遁顺布。

```
环移 = 天盘环移 = 5 步 = 225°
巽四 → 值符｜离九 → 九天｜坤二 → 九地｜兑七 → 玄武｜乾六 → 白虎｜坎一 → 六合｜艮八 → 太阴｜震三 → 腾蛇
```

### 10.8 隐层（暗干 · 地盘八神）

- **暗干**：以**时干**加于**值使门宫**，阳遁顺布、阴遁逆布三奇六仪，布满九宫。
  本盘：辛起离九，逆行得 `离九辛 → 艮八壬 → 兑七癸 → 乾六丁 → 中五丙 → 巽四乙 → 震三戊 → 坤二己 → 坎一庚`。
- **地盘八神**：八神未旋转前的底盘（以**旬首宫**起值符），即上表各宫在环移 0 步时的取值。

## 十二、精度与边界

节气时刻由 Meeus 低精度太阳视黄经算出，理论误差约 0.01°。
比对日本国立天文台《暦要項》2026 年二十四节气实测数据：

```
最大误差 13.9 分 · 平均 5.7 分 · 24/24 日期全对
```

**折合到起局上**：只有在**距节气 15 分钟以内**，节气判定才可能翻转（进而改变阴阳遁与局数）。
因此引擎在「距节气 < 60 分」或「距子夜 < 30 分」时输出 `nearBoundary` 标记，
页面会亮出**边界提示**，提醒人工核对。

**其余环节都是日级或小时级判定，不受此误差影响**：四柱、旬、符头、元、值符值使皆然。

## 十五、阴符经义理层

本节把《黄帝阴符经》的义理落成**可计算量**，加进排盘结果。
**注意：这是"以经文义理立的一层分析"，不是古传奇门格局**——它只作识别与提示，不给吉凶打分。

### 15.1 经文与注疏

《阴符经》全文仅三百余字，历代注家极多，主要数路：

| 路数 | 代表 |
| :-- | :-- |
| 托名古注集录 | **《黄帝阴符经集注》**（伊尹等**七家注**：太公、鬼谷子、广成子、范蠡、诸葛亮、张良＋李筌） |
| 治国用兵 | **唐·李筌《阴符经疏》**（道藏本题李筌，**实为宋人合编**，见《道藏提要》考证） |
| 道门义解 | **唐·张果《黄帝阴符经注》**（全篇带「传曰」；北宋《云笈七签》卷十五所收即此本） |
| 内丹 | 元明·王道渊《夹颂解注》、宋·夏元鼎、清·刘一明·闵一得等 |
| 理学／考异 | 宋·朱熹《阴符经考异》、清·黄元炳《阴符经真诠》等 |

> **一句值得注意的史实**：那套「传曰」注疏的作者是**唐·张果**（不是《云笈七签》编者——该卷所收即张果注本，
> 另有识典标注「[唐] 张果 注」的《黄帝陰符經注》可与之互证）。
> 张果**系统性地纠正李筌**——
> 「李筌以阴为暗，符为合，以此文为序首，何昧之至也」
> 「李筌等以五贼为五味，顺之可以神仙不死，诬道之甚也」
> 「李筌不知师是众，以为兵师，误也」
>
> 而《太白阴经·遁甲》正是**李筌**所作（见本仓库另一份文档）。也就是说：
> **同一人的两部书，一部被后世注家批，一部成了奇门的重要文献。** 读术数要分得清这两层。

> 📖 原文、**20 余种注本的异文表**、注本清单与未取得清单见 [阴符经汇集.md](阴符经汇集.md)。

### 15.2 版本差异（重要）

本引擎依**四种以上底本**并参，差异不止两本：

| 争点 | 各本分布 |
| :-- | :-- |
| 「**移星易宿／地发杀机**」八字 | **唐系多数无**（张果本、集注本、七注、李筌疏、云笈七签本、刘处玄等）；**宋以后一系有**（朱熹邹訢本、刘一明、闵一得、发隐、三皇玉诀）。**朱熹明确按语**：「唐褚遂良得太极真人所注本……諸本逸移星易宿、地發殺機八字，**當以褚氏本為正**」。通行本**自注**此八字系据褚遂良影印帖本、道藏本增补 |
| 「天人合**发／德**」 | **合发**：通行本、张果本、集注本、七注、李筌疏、多数；**合德**：**仅《云笈七签》本**（经文与传曰两处皆「德」） |
| 「万**变／化**定基」 | **万变**：通行本、张果本、集注本、七注、李筌疏、发隐等（多数）；**万化**：**朱熹（邹訢）、刘一明、闵一得、三皇玉诀**；**万变定机**：沈亚夫、蹇昌辰、袁淑真、李筌疏底本 |
| 食其时，百骸**理／治** | **理**：通行本、李筌疏、多数；**治**：张果本、集注本、云笈七签本 |
| 「五贼」所指 | **五行之炁**：**李筌**《疏》「五賊者，五行之炁也」、朱熹、沈亚夫等（主流）；**命·物·时·功·神**：太公、**张果**、吕望、子房、《云笈七签》传曰 |

> **「万化定基」不是误字**——它是朱熹一系的真实读法（旧版曾误判为串行致误，已更正）。
> 本引擎遇分歧处以**义理可计算性**取择（如「天地反复」对应反吟，「莫能见」对应伏吟），并在下方注明所依。

### 15.3 义理 → 可计算量（本层实现）

| 经文 | 落成的计算量 |
| :-- | :-- |
| **「爰有奇器，是生万象。八卦甲子，神机鬼藏。」** | **九宫八卦 + 六十甲子 = 奇门之器**。这是经文自己给出的接口：奇门整个排盘（§1–§11）即是此句的实现 |
| **「天有五贼，见之者昌。」** | 逐宫统计**五行相克**关系（＝「贼」）：门与宫、星与宫、天盘干与地盘干。并标注**门迫**（门克宫）／**门制**（宫克门） |
| **「三盗既宜，三才既安。」** | 天／地／人三盘互看：`地盗人(宫·门)`、`人盗天(门·星)`、`天盗地(天盘干·地盘干)`。**三者尽生或比和 → 「既宜」** |
| **「天人合德（通行本作 合发），万变（万化）定基。」** | 天盘干与地盘干成**天干五合**（甲己/乙庚/丙辛/丁壬/戊癸）→ 标「**天人合德**」 |
| **「人发杀机，天地反复。」** | **反吟**：天盘在八宫环上环移 **180°**（＝4 步） |
| **「其盗机也，天下莫能见，莫能知也。」** | **伏吟**：天盘环移 **0 步**（值符不离本宫，盘面不动） |
| **「阴阳相胜之术，昭昭乎进乎象矣。」** | **阴阳遁与顺逆布仪**（§10.1 地盘布仪方向） |
| **「食其时，百骸治；动其机，万化安。」** | 节气定局 + 应期（§2、§12） |

### 15.5 怎么用（本层的定位）

| 指标 | 稀有度 | 用法 |
| :-- | :-- | :-- |
| **门迫／门制** | 常见（八门五行与宫五行两组相克共 4／8 宫） | **逐宫细读**：哪个宫的门与宫相克，就是那一宫的现实阻力所在 |
| **五贼（贼宫）** | 极常见（本盘 8／8） | **不是筛选器**，是**注解**——告诉你这一宫的"耗损点"在哪一对五行上 |
| **三盗宜／不宜** | 本盘 7／8 不宜 | 同上，逐宫看；三才尽生的宫反而**稀少而可贵** |
| **伏吟／反吟** | **稀有（盘级）** | 出现时值得特别注意：伏吟主「藏、不动、莫能见」；反吟主「反复、翻覆」 |
| **天人合德** | **稀有（盘级）** | 出现时是强信号：天盘干与地盘干成合，主「天人相契、事有定基」 |

> ⚠️ **诚实说明**：五贼与三盗因五行相克本身常见，绝大多数宫都会「见贼／不宜」，
> 所以它们**只适合做逐宫的细节注解，不能当筛选条件**。
> 真正稀少而有判别力的是**伏吟、反吟、天人合德**这三项盘级信号。
